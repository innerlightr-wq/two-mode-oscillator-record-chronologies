## 2. Third-party dependencies

**None.** Every program in `congruence-records/certificate/` imports only the Python standard library
(`fractions`, `math`, `csv`, `os`, `sys`, `collections`). No third-party package is installed,
vendored or required. There is no network access at runtime and no data file is read at
runtime. Verified by inspection of every `import` line in the bundle.

The baseline `code/` scripts likewise use the standard library only (`math`, `fractions`,
`csv`, `hashlib`, `functools`).

The note is typeset with TeX Live packages (`amsmath`, `amsthm`, `amssymb`, `geometry`,
`booktabs`, `longtable`, `array`, `hyperref`, `microtype`), all under their own free licenses;
none of their source is redistributed here.

## 3. Third-party content reproduced

**None.** No figure, table, dataset, code fragment, proof text or quotation longer than a short
attributed phrase is reproduced from another work. The three short quoted phrases in the
companion note (from the author's own baseline note, Section 1 and Section 9) are the author's
own text. The literature discussed in Section 11 is cited, not reproduced; the statements
attributed there (Kim–Lee–Liao Definition 1.1 and Theorem 1.2; Elsner's Theorem 1.1 and its
`s = 2` exception) were read in the sources listed in `RELEASE_MANIFEST.md` and are
paraphrased.

## 5. Open items

**O-1 — `CITATION.cff` DOI placeholder. RESOLVED 2026-11-08.**
The placeholder is gone. The ambiguity that blocked it — whether `10.5281/zenodo.21796640` was
the concept or the version DOI — was settled by reading the Zenodo API rather than by guessing:

| note | version DOI | concept DOI |
|---|---|---|
| 1, *Boundary and Interior Record Chronologies…* (2026-08-04) | `10.5281/zenodo.21796640` | `10.5281/zenodo.21796540` |
| 2, *Odd/Odd Records…* (2026-11-08) | `10.5281/zenodo.24046651` | `10.5281/zenodo.24046650` |

So the number previously quoted in `README.md` was the **version** DOI. `CITATION.cff` now
describes the repository and lists both notes under `references`, each with its version DOI in
`doi:` and its concept DOI under `identifiers:`.

**O-2 — `LICENSE` scope line.** The header says the MIT grant "applies to code/ and data/".
`congruence-records/certificate/` is new code and `congruence-records/tables/` new data, both
intended to be MIT. Extend the parenthetical to name them. Not changed in
this release candidate, because editing the license header is the author's call.

**O-3 — `SHA256SUMS` at the repository root** lists the baseline files only. It is regenerated
for the release in `RELEASE_MANIFEST.md` rather than being overwritten, so the baseline
integrity list the audits used stays verifiable as-is.
